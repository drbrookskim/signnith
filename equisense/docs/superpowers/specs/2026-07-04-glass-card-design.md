# 배경 글로우 워시 + 글래스 Card 설계

## 개요

배경 톤을 화이트에 가깝게 조정한 뒤(`--bg #fbfaf7`), 애플 스타일 글래스모피즘을 적용한다.
그레인/글로우/글래스 세 가지 배경 효과를 비교한 결과, 글래스로 결정 — 단, 재무 수치 카드의 가독성을 최우선으로 하는 절제된 톤으로 구현한다.

범위: `Card` 컴포넌트 하나(`components/ui.tsx`)를 고쳐 fundamentals/swing/moat/qualitative 4개 탭 전체에 자동 반영. 새 컴포넌트나 새 API는 만들지 않는다.

---

## 1. 배경 글로우 워시 (`app/globals.css`)

글래스가 실제로 유리처럼 보이려면 뒤에 비칠 대비가 있어야 한다. `--bg`는 지금 거의 단색이므로, 상단 중심에서 옅게 퍼지는 radial gradient를 얹는다.

- 적용 대상: `body` (또는 `body::before`), 항상 표시되는 앰비언트이므로 강도는 낮게 — 강도 **~12–15%** (지난 비교 데모의 글로우 옵션 기본값 55%는 데모용 과장치, 프로덕션에는 그 1/4 수준)
- 라이트: `rgba(255,255,255, .12)` 톤의 워시 (거의 흰 배경 위라 흰색 워시는 사실상 밝기 편차만 살짝 준다 — 실제로는 `--surface` 톤 쪽으로 아주 옅게)
- 다크: 배경보다 살짝 밝은 톤 워시로 동일한 역할
- 기존 `--bg`, `--surface` 등 토큰 값은 유지, 새 토큰 없이 `body`에 gradient 레이어만 추가

## 2. 글래스 Card (`components/ui.tsx`)

`Card` 컴포넌트의 `background: var(--surface)` 를 반투명 + 블러로 교체한다.

- **투명도**: alpha ~90% 안팎 (지난 비교 데모의 45%는 효과를 보여주기 위한 과장치 — 프로덕션은 텍스트/숫자 대비 유지가 최우선이므로 훨씬 불투명하게)
- **블러**: `backdrop-filter: blur(14px) saturate(150%)` — 절제된 값. 고투명도에서는 강한 블러가 어차피 잘 안 보이므로 무리하게 키우지 않는다
- **테두리**: 기존 `1px solid var(--line)` 유지 + 상단 inset highlight 한 줄 추가해 유리 테두리 느낌 보강
- **폴백**: `@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px)))` 블록에서 완전 불투명 `var(--surface)`로 되돌림 — 구형 브라우저에서 텍스트 위에 배경이 겹쳐 보이는 사고 방지
- 새 CSS 변수 `--surface-rgb` (라이트 `255,255,255` / 다크 `30,30,27`) 를 라이트·다크 테마 토큰 블록에 추가해 `rgba()` 계산에 사용

## 3. 검증

- 로컬 dev 서버에서 4개 탭(fundamentals/swing/moat/qualitative) × 라이트/다크 총 8가지 조합을 눈으로 확인
- 재무 수치(Stat, MetricBar)와 텍스트가 배경 워시 위에서도 또렷이 읽히는지가 통과 기준
- 별도 자동 테스트는 추가하지 않음 (순수 스타일 변경, 로직 없음)
