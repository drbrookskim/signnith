# exec-plans/ — 마일스톤별 실행 계획

이 디렉토리는 8주 개발 로드맵의 스프린트별 상세 실행 계획을 담습니다.
각 파일은 해당 마일스톤의 목표, 태스크 분해, 완료 기준, 위험 요소를 포함합니다.

## 전체 타임라인

```
Week 1-2  │ PHASE 1: 서버리스 환경 설정 및 API 연동
Week 3-4  │ PHASE 2: 동기형 API 및 프론트엔드 연동 (Module 1, 4)
Week 5-6  │ PHASE 3: 비동기 AI 파이프라인 구축 (Module 2, 3)
Week 7-8  │ PHASE 4: CI/CD 자동화 및 운영 배포
```

## 파일 목록

| 파일명 | 기간 |
|--------|------|
| `phase1-infra-setup.md` | Week 1~2: 인프라 및 환경 설정 |
| `phase2-sync-api.md` | Week 3~4: 동기형 API 개발 |
| `phase3-async-ai.md` | Week 5~6: 비동기 AI 파이프라인 |
| `phase4-cicd.md` | Week 7~8: CI/CD 및 배포 |
