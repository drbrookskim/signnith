# product-specs/ — 수용 기준 (Acceptance Criteria)

이 디렉토리는 각 모듈과 마일스톤의 수용 기준(AC)을 정의합니다.
수용 기준은 "완료"의 정의입니다. PR에서 AC 번호를 참조하고, 해당 AC가 충족되어야 머지합니다.

## 파일 목록

| 파일명 | 내용 |
|--------|------|
| `AC-M1-fundamental.md` | Module 1 펀더멘털 엔진 수용 기준 |
| `AC-M2-moat.md` | Module 2 해자 트래커 수용 기준 |
| `AC-M3-qualitative.md` | Module 3 AI 분석기 수용 기준 |
| `AC-M4-technical.md` | Module 4 기술적 분석 수용 기준 |
| `AC-INFRA.md` | 인프라 및 CI/CD 수용 기준 |

## AC 번호 체계

`AC-{모듈코드}-{일련번호}` 형식을 사용합니다.
예: `AC-M1-003`은 Module 1의 세 번째 수용 기준입니다.
