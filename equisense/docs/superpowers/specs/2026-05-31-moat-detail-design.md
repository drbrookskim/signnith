# 해자(Moat) 탭 상세 설명 강화 — 설계 문서

Date: 2026-05-31

---

## 목표

해자 탭에 세 가지 요소를 추가하여 사용자가 점수의 의미와 근거를 직관적으로 이해하도록 한다.

1. **전체 해자 개념 소개 섹션** — 해자 개념 + 4차원 상세 설명
2. **지표 카드 강화** — 점수 바 + rationale 수치 + 차원별 상세 설명
3. **Analyst Note 자동 생성** — 템플릿 서술(A) + 강점·약점 구조(C) 병합

## 1. 해자 개념 소개 섹션

**위치**: 회사명/등급 헤더 바로 아래, 차트 위

**내용**:
- 해자 개념 한 문단 (워런 버핏 개념, 구조적 경쟁 우위)
- 4개 차원을 2×2 그리드 카드로 표시

**각 차원 카드 내용**:

| 차원 | 이모지 | 한 줄 정의 | 측정 방법 | 점수 기준 |
|------|--------|-----------|-----------|-----------|
| 비용 우위 | 🏭 | 경쟁사보다 낮은 원가로 생산하는 능력 | 영업이익률 + (100 - 부채비율) 평균 | 영업이익률 30%↑ → 만점 |
| 무형 자산 | 💎 | 브랜드·특허 등 모방하기 어려운 자산 | ROE를 브랜드 가치의 대리 지표로 활용 | ROE 25%↑ → 만점 |
| 전환 비용 | 🔒 | 고객이 다른 제품으로 옮기기 어려운 마찰 | 매출 CAGR + 성장 방향성 보정 | CAGR 12%↑ → 만점 |
| 네트워크 효과 | 🌐 | 사용자 증가가 가치를 키우는 선순환 | FCF 마진으로 수익 창출력 측정 | FCF 마진 15%↑ → 만점 |

---

## 2. 지표 카드 강화

**현행**: 차원명 + 점수 + rationale 한 줄

**변경 후**:
- 이모지 + 차원명 + 점수 (우측)
- 점수 바 (0~10 시각화, 색상: 7.5↑ → indigo, 5↑ → violet, 미만 → zinc)
- rationale 수치 (현행 유지)
- **상세 설명 한 줄**: 이 차원이 해자와 어떻게 연결되는지 고정 문구

**차원별 상세 설명 고정 문구**:
- 비용 우위: "높은 영업이익률과 낮은 부채는 경쟁사 대비 지속적 원가 우위를 시사합니다."
- 무형 자산: "ROE는 브랜드·특허가 만들어내는 초과수익률의 대리 지표입니다."
- 전환 비용: "안정적·성장하는 매출은 고객이 이탈하기 어려운 구조를 반영합니다."
- 네트워크 효과: "FCF 마진이 높을수록 규모 확장 시 수익성이 자기강화됩니다."

## 3. Analyst Note 자동 생성

`moat.ts`의 `calculateMoat()` 함수 내에서 `analyst_note`를 자동 생성한다.

**구조 (A+C 병합)**:

기업명: `fundamentals.name ?? fundamentals.ticker` 사용

```
[단락 1 — 템플릿 서술]
{기업명}은 {등급} 해자로 평가됩니다. {가장 높은 차원}({점수}점)이 가장 강한
경쟁 기반으로, {rationale}. {가장 낮은 차원}({점수}점)은 상대적으로 약합니다.

[단락 2 — 강점·약점 구조]
✅ 강점: 점수 6.0↑ 차원의 rationale 나열
⚠️ 개선 필요: 점수 5.0 미만 차원의 rationale 나열
(해당 항목 없으면 해당 섹션 생략)
```

**등급별 서술 어조**:
- WIDE (7.5↑): "강력한 경제적 해자를 보유합니다"
- NARROW (5.0↑): "일부 구조적 우위가 확인됩니다"
- NONE (미만): "뚜렷한 해자가 확인되지 않습니다"

**타입 변경 없음**: `MoatAnalysis.analyst_note: string | null` 유지, 계산 후 항상 문자열 반환.
